# article-digest

按 alphaXiv 风格为文章生成精简、通俗、像人写的中文摘要与概述（TL;DR + 结构化要点），支持从链接、导出文件或长截图提取内容，自动识别并只保留最关键的原文图表。

## 能力

- **多来源获取**：链接抓取（alphaXiv/arXiv/普通网页）→ 用户提供 → 本地文件（docx/pdf/md/长截图）
- **长截图 OCR**：Windows 自带中文 OCR（PowerShell + .NET，零依赖，无需 Python），含 OCR 硬伤修正清单
- **图表取舍**：按坐标定位图表区域，最多保留 2~3 张「能一图回答所以呢」的关键图，支持按坐标裁剪原图
- **业界对照分析**：每篇必做——业界定位、局限与挑战、适用场景判断
- **写作规范**：核心价值优先（不忠实压缩原文）、背景自足副标题、踩坑转「场景+比喻+后果+解法」小故事、语气红线（禁对仗句式/加粗轰炸/排比小标题）
- **句数硬约束**：各节句数上限逐节自查，禁止用分号/列表碎片规避
- **证据定位**：关键事实标注（原文第 X 节）；OCR 文章用段落号，链接文章用小节标题
- **AI 观点与原文事实分离**：同节混排按「原文观点段 + AI 观点段」两段式分段；AI 专属章节标题带（AI 观点/AI 提炼）标记

## 结构

```
article-digest/
├── SKILL.md                    # 主规则文件（工作流程 + 写作规范 + 检查清单）
├── scripts/
│   ├── extract_article.ps1     # 长图切分 + 中文 OCR + 逐行坐标输出
│   └── crop_figure.ps1         # 按坐标从原图裁剪图表
├── assets/                     # 预留
└── references/                 # 预留
```

## 使用

将本目录放入 OpenClaw/CoMagic 的 skills 目录（如 `~/.comagic/skills/`），对话中说「总结文章」「提炼摘要和概述」「提炼要点」即可触发。

## 环境要求

- Windows（OCR 脚本依赖 Windows.Media.Ocr 与 System.Drawing）
- PowerShell 5.1+（无需安装任何包）
